# 개발 마일스톤

1차 버전 목표: **3개 지역, 보스 2, 메인 퀘스트 도입부를 30~60분 동안 플레이할 수 있는 빌드.**
각 마일스톤은 "완료 조건"을 모두 만족해야 닫는다. 끝나면 `CLAUDE.md`의 단계 표도 함께 갱신한다.

| | 마일스톤 | 핵심 결과물 | 상태 |
|---|---|---|---|
| M1 | 움직임과 손맛 | 8방향 이동·3타 콤보·경공·피격, 산적 AI, 카메라 | ✅ 완료 |
| M2 | 월드의 뼈대 | TileMapLayer 지역 2개, 지역 전환, 길찾기 하는 적 | ⬜ 다음 |
| M3 | 무공과 기세 | 기세·초식 4종·적 3종·보스 1 (산적 두목) | ⬜ |
| M4 | 강호의 사람들 | 대화·퀘스트 1개·인벤토리·비급·저장 | ⬜ |
| M5 | 옷을 입히다 | SpriteCook 캐릭터·타일셋, ElevenLabs 사운드 | ⬜ |
| M6 | 1차 버전 | 지역 3개, 보스 2, 의뢰·세력, 밸런스, 배포 빌드 | ⬜ |

M4가 끝나면 **버티컬 슬라이스**(시작 마을 → 죽림 → 산적 두목)가 더미 그래픽으로 처음부터 끝까지 이어져야 한다. M5는 그 위에 그래픽과 소리를 입히는 단계다.

---

## M1 — 움직임과 손맛 ✅
- [x] 480x270 정수 배율, Nearest, 픽셀 스냅
- [x] 8방향 이동, 3타 콤보(3타째 범위·넉백 큼), 공격 후 경공 캔슬
- [x] 경공(내공 15, 무적, 잔상), 피격 무적·넉백, 사망·재시작, 운기조식
- [x] 히트스톱·화면 흔들림·데미지 숫자, 기혈/내공 HUD
- [x] 산적 AI 1종 (배회 → 추격 → 예비동작 → 베기 → 경직)
- [x] pixelfx 베기·회전베기·적중 이펙트

## M2 — 월드의 뼈대
목표: 지금 코드로 그리는 임시 바닥을 진짜 타일맵으로 바꾸고, 지역 사이를 오갈 수 있게 한다.

**작업**
- [ ] 임시 타일셋 PNG (16x16, 풀·흙길·물·대나무·벽, 코드로 생성) + TileSet 리소스 (충돌·내비게이션 레이어 포함)
- [ ] `Region` 기본 씬: 바닥/장식/충돌 TileMapLayer, 출구(Area2D), 진입 지점, 카메라 경계 자동 설정
- [ ] 지역 관리자 (autoload): 페이드 아웃 → 지역 씬 교체 → 진입 지점에 배치 → 페이드 인
- [ ] 지역 2개: `village_outskirts`(시작 마을 외곽), `bamboo_entrance`(죽림 입구)
- [ ] 지형 이동: 강(통과 불가), 얕은 물(느려짐), 덤불(가려짐)
- [ ] 적 길찾기: NavigationAgent2D로 나무·바위를 돌아서 추격
- [ ] 지역별 적 스폰 지점 (지역을 다시 들어오면 재배치)
- [ ] `main.gd`의 테스트 맵 조립 코드 정리

**완료 조건**
- 마을 외곽 ↔ 죽림 입구를 막힘 없이 왕복할 수 있다 (진입 위치·카메라 경계가 맞음)
- 산적이 장애물에 걸리지 않고 돌아서 쫓아온다
- 헤드리스 실행 오류 0, 지역 전환 중 깜빡임·끊김 없음

## M3 — 무공과 기세
목표: 기획의 전투 시스템을 완성하고 첫 보스를 만든다.

**작업**
- [ ] **기세 게이지**: 적마다 기세 값, 공격으로 깎임 → 0이 되면 경직(추가 피해, 시각 표시) → 회복
- [ ] 초식 데이터화 (Resource): 피해, 범위, 내공 소모, 판정 시점, 이펙트 id
- [ ] 초식 4종: 기본 3타 / 장풍(원거리, 내공) / 회피 반격(경공 직후 공격) / 필살기(내공 대량, 범위)
- [ ] 내공 흐름 조정: 적중 충전, 경공·장풍·필살기 소모
- [ ] 적 2종 추가: 궁수(거리 유지, 화살), 자객(돌진 베기)
- [ ] 적 공격 예고(빨간 범위·"!") 통일, 화살은 베기로 쳐낼 수 있음
- [ ] **보스: 산적 두목** — 패턴 3개(내려찍기, 돌진, 부하 소환) + 체력 50% 이하 강화, 보스 체력바
- [ ] pixelfx 추가: 장풍, 필살기, 기세 붕괴, 보스 내려찍기

**완료 조건**
- 산적 두목을 피격 없이 깰 수도 있고, 실수하면 질 수도 있다 (2~3분 전투)
- 기세 붕괴가 눈에 보이고 전투에서 노릴 이유가 있다
- 초식 4종이 모두 쓸모가 있다 (한 가지만 연타하는 게 최선이 아님)

## M4 — 강호의 사람들
목표: 탐험과 전투 사이에 이야기와 성장을 넣는다.

**작업**
- [ ] 한글 도트 폰트 적용 (예: Galmuri, OFL) — 8px HUD 텍스트 가독성 문제 해결
- [ ] 대화 시스템: 데이터(JSON/Resource) 기반, 선택지, 조건(퀘스트·호감도), 초상화 자리
- [ ] NPC: 마을 촌장, 상인, 폐허의 생존자
- [ ] 퀘스트 시스템 + 메인 퀘스트 1 "멸문의 흔적": 촌장과 대화 → 폐허 본문파 조사 → 단서 → 죽림 산적 두목 처치
- [ ] 인벤토리: 회복약, 열쇠 아이템, 비급
- [ ] 비급 획득 → 초식 해금 (M3의 장풍을 비급으로 얻게)
- [ ] 세력 호감도 변수(정파·사파·마교)와 대화 선택지 반영 (M6에서 본격 사용)
- [ ] 저장/불러오기: `user://` JSON (위치·지역·스탯·인벤토리·퀘스트·호감도), 타이틀에서 이어하기

**완료 조건**
- 새 게임 → 대화 → 퀘스트 수락 → 비급 획득 → 초식 해금 → 보스 처치 → 퀘스트 완료가 이어진다
- 아무 시점에서 저장·종료 후 불러오면 같은 상태로 돌아온다
- **버티컬 슬라이스 완성** (더미 그래픽)

## M5 — 옷을 입히다
목표: 더미 그래픽과 무음 상태를 실제 에셋으로 바꾼다.

**작업**
- [ ] 아트 방향 확정: 팔레트(16~32색), 캐릭터 비율, 레퍼런스 시트
- [ ] SpriteCook 캐릭터: 주인공·산적·궁수·자객·두목·NPC 3명, 8방향 idle/walk/attack/hurt
- [ ] `dummy_body.gd` → AnimatedSprite2D 몸체로 교체 (같은 인터페이스, 파일명 `대상_동작_방향_번호`)
- [ ] SpriteCook 타일셋: 풀·흙길·마을·대나무숲·강·폐허, 오브젝트(집, 울타리, 바위, 대나무)
- [ ] ElevenLabs 효과음: 베기 3종, 적중, 경공, 장풍, 피격, 발소리(지형별), UI
- [ ] ElevenLabs BGM: 마을, 죽림, 보스전 / 오디오 버스(BGM·SFX·보이스) 분리
- [ ] 이펙트 색을 새 팔레트에 맞춰 다시 뽑기

**완료 조건**
- 버티컬 슬라이스에 더미 그래픽이 하나도 남아 있지 않다
- 모든 행동에 소리가 있고, 지역마다 BGM이 바뀐다

## M6 — 1차 버전
목표: 지역 3개로 확장하고, 남에게 건넬 수 있는 빌드를 만든다.

**작업**
- [ ] 지역 3: 정파 문파 거점 (마을·수련장·장문인 거처)
- [ ] 보스 2: 정파 문파의 시험 상대 (또는 멸문과 연결된 인물)
- [ ] 문파 의뢰 2~3개, 마을 심부름 2~3개
- [ ] 세력 호감도에 따른 NPC 반응·문파 가입 가능 여부
- [ ] 문파 무공 1종 습득, 수련으로 강화
- [ ] 나침반/지도, 숨은 비급 1~2개, 동굴 1개
- [ ] 타이틀·설정(음량, 키 안내)·일시정지 메뉴
- [ ] 밸런스: 적 체력·피해, 내공 수급, 보스 난이도
- [ ] macOS / Windows 내보내기 (`*.json` 비리소스 필터 포함)

**완료 조건**
- 처음 하는 사람이 설명 없이 30~60분 동안 끝까지 플레이할 수 있다
- 내보낸 빌드에서 저장·불러오기·이펙트·사운드가 모두 동작한다

## 병렬 작업 메모
- M2~M4는 `player.gd`·`enemy.gd`·지역 코드를 함께 건드리므로 **한 흐름으로 순서대로** 진행한다.
- M5의 에셋 생성(SpriteCook·ElevenLabs)은 코드와 겹치지 않으므로 M4와 **별도 세션으로 병렬** 진행할 수 있다.
- M6의 지역 3개는 `Region` 구조가 안정되면 지역별로 나눠 병렬 진행할 수 있다.
