# 개발 마일스톤

이야기와 설정은 [STORY.md](STORY.md).

1차 버전 목표: **초반 "한 시진"(Q0~Q5)과 그 이후 지역 2곳을 30~60분 동안 플레이할 수 있는 빌드.**
각 마일스톤은 "완료 조건"을 모두 만족해야 닫는다. 끝나면 `CLAUDE.md`의 단계 표도 함께 갱신한다.

| | 마일스톤 | 핵심 결과물 | 상태 |
|---|---|---|---|
| M1 | 움직임과 손맛 | 8방향 이동·3타 콤보·경공·피격, 적 AI, 카메라 | ✅ 완료 |
| M2 | 돌다리 마을 | TileMapLayer 마을 + 실내, 지역 전환, 길찾기 하는 적 | ⬜ 다음 |
| M3 | 기수식과 기세 | Q 기수식 커맨드, 일섬, 기세, 황가 일당 3인 전투 | ⬜ |
| M4 | 한 시진 | 대화·퀘스트·시진 시계·자동 세이브·Q0~Q5·오프닝 | ⬜ |
| M5 | 옷을 입히다 | SpriteCook 캐릭터·타일셋, ElevenLabs 사운드 | ⬜ |
| M6 | 1차 버전 | Q5 이후 지역 2곳, 보스 2, 의뢰, 배포 빌드 | ⬜ |

M4가 끝나면 **버티컬 슬라이스**("한 시진" 처음부터 끝까지)가 더미 그래픽으로 이어져야 한다. M5는 그 위에 그래픽과 소리를 입히는 단계다.

## M1 — 움직임과 손맛 ✅
- [x] 480x270 정수 배율, Nearest, 픽셀 스냅
- [x] 8방향 이동, 3타 콤보(3타째 범위·넉백 큼), 공격 후 경공 캔슬
- [x] 경공(내공 15, 무적, 잔상), 피격 무적·넉백, 사망·재시작, 운기조식
- [x] 히트스톱·화면 흔들림·데미지 숫자, 기혈/내공 HUD
- [x] 적 AI 1종 (배회 → 추격 → 예비동작 → 베기 → 경직) — 황가 일당의 바탕
- [x] pixelfx 베기·회전베기·적중 이펙트

## M2 — 돌다리 마을
목표: 임시 바닥을 진짜 타일맵으로 바꾸고, "한 시진"의 무대를 만든다.

**작업**
- [ ] 임시 타일셋 PNG (16x16, 흙길·돌길·풀·물·나무 벽·지붕·다리, 코드로 생성) + TileSet 리소스 (충돌·내비게이션 레이어)
- [ ] `Region` 기본 씬: 바닥/장식/충돌 TileMapLayer, 출구(Area2D), 진입 지점, 카메라 경계 자동 설정
- [ ] 지역 관리자 (autoload): 페이드 아웃 → 지역 씬 교체 → 진입 지점에 배치 → 페이드 인
- [ ] 돌다리 마을 바깥: 객잔 앞, 큰길, 무관 앞, 돌다리, **다리 밑 뒷골목**(Q3·Q4 무대)
- [ ] 실내 3곳: 객잔 뒷방(헛간, 시작 지점), 객잔, 무관
- [ ] 물(통과 불가)과 다리, 좁은 골목의 지형 (Q4 전투에서 지형을 활용할 수 있게)
- [ ] 적 길찾기: NavigationAgent2D로 장애물을 돌아서 추격
- [ ] NPC 자리 표시 (옥분, 마 사범, 엽 노인 — 대화는 M4)
- [ ] `main.gd`의 테스트 맵 조립 코드 정리

**완료 조건**
- 헛간 → 객잔 → 큰길 → 무관 → 돌다리 → 뒷골목을 막힘 없이 오갈 수 있다 (진입 위치·카메라 경계가 맞음)
- 적이 장애물에 걸리지 않고 돌아서 쫓아온다
- 헤드리스 실행 오류 0, 지역 전환 중 깜빡임 없음

## M3 — 기수식과 기세
목표: 이 게임만의 전투(기수식 커맨드)를 만들고, 첫 전투인 황가 일당을 완성한다.

**작업**
- [ ] **기수식**: Q 유지 → 자세(이동 정지/감속, 시각 표시) → 바라보는 방향 기준 상대 방향(앞·뒤·좌·우) + J 커맨드 인식
- [ ] 커맨드 입력 버퍼와 판정 (입력 허용 시간, 잘못된 입력 처리, 입력 표시 UI)
- [ ] 초식 데이터화 (Resource): 커맨드, 피해, 범위, 내공 소모, 판정 시점, 이펙트 id
- [ ] 초식 **일섬** (돌진하며 한 번에 베는 일격) + pixelfx 이펙트
- [ ] **기세 게이지**: 적마다 기세 값, 공격으로 깎임 → 0이면 경직(추가 피해, 시각 표시) → 회복. 일섬은 기세를 크게 깎는다
- [ ] 내공 흐름: 적중 충전, 경공·기수식/초식 소모, 운기조식 회복
- [ ] **황가 일당**: 부하 둘(기존 AI 변형) + 우두머리 황가(기세 높음, 패턴 2~3개, 부하가 쓰러지면 강해짐)
- [ ] 무기: 연습용 목검 (Q2에서 받음) — 피해·리치 수치

**완료 조건**
- 기수식 커맨드가 8방향 어디를 보든 똑같이 나가고, 실수로 발동되지 않는다
- 기본 공격만으로는 황가를 이기기 어렵고, 일섬으로 기세를 무너뜨리면 확실히 유리하다
- 황가 일당 전투가 2~3분 안에 끝나며, 지면 왜 졌는지 알 수 있다

## M4 — 한 시진
목표: 초반 퀘스트 Q0~Q5를 처음부터 끝까지 이어 붙인다.

**작업**
- [ ] 한글 도트 폰트 적용 (예: Galmuri, OFL) — 8px 텍스트 가독성 해결
- [ ] 대화 시스템: 데이터 기반, 선택지, 속마음 대사 구분, 웹툰 컷 느낌의 연출 검토
- [ ] 퀘스트 시스템: 단계·목표 표시, 단계 완료 이벤트
- [ ] **시진 시계**: 화면 표시, 퀘스트 단계 완료 시 정해진 시각으로 이동 (실시간 아님)
- [ ] **기억 속 컷** 화면: 1화 컷 몇 장 = 단서 (Q0에서 열림, Q3 길잡이)
- [ ] 인벤토리: 심부름 물건, 연습용 목검
- [ ] Q0 낯선 몸 → Q1 평소와 다른 서진 → Q2 급조 수련(일섬 습득) → Q3 죽음의 장소 → Q4 한 시진의 끝 → Q5 달라진 이야기
- [ ] **자동 세이브**: 황가 전투 직전. 죽으면 1화 엔딩 컷 + "뒤로가기" → 전투 직전부터 재시작
- [ ] 수동 저장/불러오기: `user://` JSON (지역·위치·스탯·인벤토리·퀘스트·시각), 타이틀에서 이어하기
- [ ] 오프닝(침대 → 웹툰 → 뒤로가기 → 암전 → 낯선 천장)과 Q4 후 "이 장면은 원작에 없다" 연출

**완료 조건**
- 새 게임부터 Q5까지 막힘 없이 이어진다 (**버티컬 슬라이스 완성**, 더미 그래픽)
- 황가 전투에서 죽으면 몇 초 안에 전투 직전으로 돌아온다
- 아무 시점에서 저장·종료 후 불러오면 같은 상태로 돌아온다

## M5 — 옷을 입히다
목표: 더미 그래픽과 무음 상태를 실제 에셋으로 바꾼다.

**작업**
- [ ] 아트 방향 확정: 팔레트(16~32색), 캐릭터 비율, 레퍼런스 시트
- [ ] SpriteCook 캐릭터: 서진, 옥분, 마 사범, 황가, 부하 2, 엽 노인 — 8방향 idle/walk/attack/hurt (+ 기수식 자세)
- [ ] `dummy_body.gd` → AnimatedSprite2D 몸체로 교체 (같은 인터페이스, 파일명 `대상_동작_방향_번호`)
- [ ] SpriteCook 타일셋: 마을 길, 객잔·무관 건물, 실내, 강과 돌다리, 뒷골목, 오브젝트
- [ ] 오프닝·컷 연출용 일러스트 (침대 장면, 1화 컷 몇 장, 엔딩 컷)
- [ ] ElevenLabs 효과음: 베기 3종, 일섬, 적중, 경공, 기수식, 피격, 발소리, UI, 웹툰 뒤로가기
- [ ] ElevenLabs BGM: 마을, 긴장(한 시진 끝 무렵), 전투 / 오디오 버스(BGM·SFX·보이스)
- [ ] 이펙트 색을 새 팔레트에 맞춰 다시 뽑기

**완료 조건**
- 버티컬 슬라이스에 더미 그래픽이 하나도 남아 있지 않다
- 모든 행동에 소리가 있고, 장면마다 BGM이 바뀐다

## M6 — 1차 버전
목표: Q5 이후 이야기를 붙이고, 남에게 건넬 수 있는 빌드를 만든다.
(Q5 이후 이야기·지역·보스는 [STORY.md](STORY.md)의 "아직 정하지 않은 것"이 정해지면 구체화한다.)

**작업**
- [ ] 엽 노인의 의뢰 게시판 (의뢰 2~3개)
- [ ] 다음 지역 2곳 + 보스 2
- [ ] 적 2종 추가 (예: 궁수, 자객)
- [ ] 초식 2~3종 추가 (기수식 커맨드)
- [ ] 세력·문파 요소 (이야기에서 역할이 정해지면)
- [ ] 떡밥 배치: 이상한 유물, 정체불명의 무공 흔적
- [ ] 타이틀·설정(음량, 키 안내)·일시정지 메뉴
- [ ] 밸런스: 적 체력·피해, 내공 수급, 보스 난이도
- [ ] macOS / Windows 내보내기 (`*.json` 비리소스 필터 포함)

**완료 조건**
- 처음 하는 사람이 설명 없이 30~60분 동안 끝까지 플레이할 수 있다
- 내보낸 빌드에서 저장·불러오기·이펙트·사운드가 모두 동작한다
